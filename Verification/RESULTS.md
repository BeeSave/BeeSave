## Ограничения проверки

Сеть, объём данных и Keychain включаются отдельными флагами; эти три проверки в текущей локальной серии пропущены. На предыдущем этапе неподписанная проверка Keychain получила −34018; для Touch ID и режима без пароля нужны корректные права в подписи Apple. Полная системная/UI-приёмка остаётся в ACCEPTANCE.md. Визуальная проверка иконки Dock в этом обновлении не проводилась. Сборка подписана ad hoc и не нотариализована.

GitHub Releases и latest.json подготовлены как основа для будущего обновления. Сам механизм автоматического обновления пока не реализован.

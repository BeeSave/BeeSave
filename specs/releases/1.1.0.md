# BeeSave 1.1.0 — новый интерфейс

- Фон и палитра из иконки приложения, ясная иерархия Главной, компактные карточки и общий график доходов/расходов.
- Три шага первого запуска: пароль, конфигурация, сохранение и проверка ключа восстановления.
- Выпадающий календарь диапазона и сгруппированные фильтры с предварительным числом записей, отменой и видимыми метками условий.
- Формы с дополнительными полями по запросу, возврат из создания справочника без потери ввода, действия в контексте счёта.
- Обновлённые история, бюджеты, отчёты, настройки и мастера переноса; читаемые даты, суммы и частичные итоги.
- **BeeSave → Проверить обновление**: проверка выпуска GitHub, загрузка архива и проверка SHA-256. Установка выполняется вручную.

**Платформа:** Apple Silicon (arm64), macOS 26 и новее. Версия 1.1.0, сборка 5. Сохранены идентификатор приложения и совместимость базы/паролей/ключа восстановления/полных копий.

**Установка:** скачайте `BeeSave-macos-arm64.zip`, распакуйте архив, завершите BeeSave и замените прежнее приложение. Контрольная сумма находится в `.sha256`; `latest.json` содержит метаданные обновления.

**Проверка:** 50 локальных тестов прошли без ошибок; четыре отдельные проверки пропущены в общей серии. Контроль 100 000 операций пройден отдельно. Release и строгая проверка локальной подписи успешны.

**Статус сборки:** подпись ad hoc, без нотариализации. Touch ID и вход без пароля требуют корректной подписи Apple с правами Keychain. Нативная приёмка интерфейса частичная; оставшиеся сценарии первого запуска, защиты, переноса и доступности перечислены в [отчёте 002](https://github.com/BeeSave/BeeSave/blob/v1.1.0/specs/changes/002-ui-redesign-acceptance.md).

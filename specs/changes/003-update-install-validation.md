**Заказчик выполняет нативные проверки самостоятельно, в том числе на macOS 27.** Кандидат поддерживает 26.0 и новее; наличие именно macOS 26 не требуется для его запуска на 27. В готовом пакете `LSMinimumSystemVersion=26.0`; Mach-O содержит `minos 26.0`, `sdk 27.0`. Проверка 26 остаётся отдельной проверкой нижней границы; результат 27 на неё не переносится. Системное доверие/Open Anyway подтверждает сам пользователь. Инструкция — `003-update-install-user-test.md`.

Пропуск, частичная проверка или отсутствие стенда не считаются успехом. Последнее поручение заказчика «ладно, продолжи выкладку на github» разрешает предварительную публикацию до завершения матрицы. Кандидат передаётся как **Pre-release**, стабильная 1.1.0 остаётся последней стабильной. Это не отменяет требование сквозной автоматической установки и не означает завершение всей фичи. При публикации загружаются прежние проверенные байты шести вложений; результат публичной доставки проверяется отдельно.

## Воспроизведение локальных проверок

```sh
BEESAVE_PERF=1 BEESAVE_NETWORK=1 BEESAVE_UPDATE_NETWORK=1 swift test -c release
python3 scripts/test_sparkle_network.py /path/to/verified/patched/Sparkle/source
python3 scripts/test_sparkle_package.py /path/to/Release/BeeSave.app YOUR_CERTIFICATE_IDENTITY
python3 scripts/test_update_coordinator.py /path/to/UISmoke/products YOUR_CERTIFICATE_IDENTITY
python3 scripts/package_release.py /path/to/Release/BeeSave.app /path/to/verified/Sparkle/bin
python3 scripts/verify_release.py Dist
```

Запускать на вымышленных данных. Системные критерии выполняются по плану 003 в отдельном профиле. При изменении кода, версии, сертификата или упаковки повторяются затронутые проверки на новых байтах.

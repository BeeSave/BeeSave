# BeeSave

«Пчелиное сбережение»: пчела собирает нектар в соты, а BeeSave помогает учитывать деньги и собирать сбережения. Название созвучно «Be safe».

Нативное приложение домашнего бюджета для Apple Silicon, macOS 26 и новее. Требования — `SPEC.md`; этапы и проверки — `PLAN.md`; фактическая приёмка — `ACCEPTANCE.md`.

Реализованы счета и пять типов записей, сверка остатка, категории/подкатегории и проекты, два типа бюджетов, мультивалютные отчёты, настройка Главной, CSV-мастер, зашифрованные полные копии и восстановление. Расчёты и файлы работают без интернета. Сеть используется для валютных данных CBR/Frankfurter и проверки/скачивания обновлений из GitHub по команде пользователя.

В исходниках реализован [редизайн 002](specs/changes/002-ui-redesign.md): фон и палитра иконки, три шага первого запуска, компактная Главная, календарь диапазона, сгруппированные фильтры и формы с дополнительными полями по запросу. [План](specs/changes/002-ui-redesign-plan.md) и [результаты проверки](specs/changes/002-ui-redesign-acceptance.md) описывают текущий статус. Редизайн подготовлен к выпуску 1.1.0, сборка 5.

Текущий архив — локальная тестовая сборка с входом паролем. Для Touch ID и режима без дополнительного входа нужна подписанная сборка с правами Data Protection Keychain. Полная приёмка всех режимов пока не завершена; подробности в `ACCEPTANCE.md`.

## Запуск готовой сборки

Последняя опубликованная версия — в [GitHub Releases](https://github.com/BeeSave/BeeSave/releases/latest). Порядок выпуска и контракт обновлений описаны в [RELEASES.md](RELEASES.md). Изменение базовых требований — [specs/changes/001-update.md](specs/changes/001-update.md); план и результаты — [001-update-plan.md](specs/changes/001-update-plan.md).

1. Распакуйте `Dist/BeeSave-1.1.0-arm64.zip` в локальную папку и откройте `BeeSave.app`.
2. На первом запуске оставьте включённым пароль. Введите фразу не короче 12 символов и повторите её.
3. Выберите базовую валюту и конфигурацию входа, затем сохраните показанный ключ восстановления отдельно от этого Mac. Подтвердите сохранение и повторно введите ключ. Он понадобится для открытия полной копии на другом устройстве.
4. Создайте счёт в «Мои счета», укажите валюту, дату открытия и начальный остаток. Затем добавляйте расходы кнопкой «Добавить расход», доходы и переводы через соседнее меню или действия истории счёта.

Сборка подписана ad hoc для локальной разработки; она не нотариализована для распространения. Если система требует доверенную подпись, используйте запуск из Xcode по следующей инструкции.

## Запуск из Xcode

1. Откройте `BeeSave.xcodeproj` в Xcode 27.
2. Выберите схему **BeeSave** и **My Mac**. Нажмите **⌘R**.
3. Встроенная библиотека подключена как локальный Swift Package; исходники Argon2 входят в проект. Загрузка сторонних пакетов и установка сервера не нужны.

Если Xcode сообщает о FinderInfo при подписи, перенесите Derived Data в `/private/tmp/BeeSaveRun` через настройки Locations. На этой машине файловый провайдер Documents добавлял метаданные к собранным пакетам; сборка вне Documents прошла.

Командная сборка из папки проекта:

```sh
xcodebuild -project BeeSave.xcodeproj -scheme BeeSave \
  -configuration Release -destination 'generic/platform=macOS' \
  -derivedDataPath /private/tmp/BeeSaveRun build
```

Результат: `/private/tmp/BeeSaveRun/Build/Products/Release/BeeSave.app`.

## Подпись для всех режимов входа

На текущем Mac нет действующих сертификатов подписи. Неподписанный системный тест Keychain получил −34018; парольная оболочка и ключ восстановления от Keychain не зависят.

В Xcode у target BeeSave откройте **Signing & Capabilities**, выберите свою команду Apple Developer и сертификат Apple Development. В **Build Settings → Code Signing Entitlements** укажите `App/BeeSaveSigned.entitlements`; этот файл содержит группу только данного приложения. Уберите заданное в проекте значение `-` у Code Signing Identity, чтобы Xcode использовал сертификат. Проверьте, что профиль разрешает application identifier и Keychain access group. Учётную запись Apple и новые пароли вводит владелец Mac.

Управление Data Protection Keychain определяется правами в подписи; это описано в [документации Apple об ошибке missing entitlement](https://developer.apple.com/documentation/security/errsecmissingentitlement). При смене команды подписи создавайте проверенную полную копию заранее: доступ к прежним элементам Keychain может измениться. Ключ восстановления позволяет заново настроить локальный вход.

После настройки подписи нужно вручную проверить четыре сочетания пароль/Touch ID, отмену биометрии, блокировку Mac и инвалидирование привязки при смене отпечатков. Парольный вход и ключ восстановления доступны как альтернативы согласно SPEC.md.

## Обычная работа

- В новой сборке настройка проходит через пароль → конфигурацию → сохранение и проверку ключа. После завершения Главная предлагает создать первый счёт или импортировать операции.
- На Главной основная команда — **Добавить расход**; доход и перевод находятся рядом в меню. В истории счёта эти действия сразу используют выбранный счёт. Проект, комментарий и участие в бюджетах открываются в группе **Дополнительно**; курсы появляются при необходимости пересчёта.
- Кнопка периода открывает календарь диапазона, **Фильтры** — окно условий с предварительным числом записей. Изменения вступают в силу после **Применить**; **Отмена** сохраняет текущую выборку. Применённые условия видны отдельными метками.
- **⌘N** — расход; **⇧⌘N** — доход; **⇧⌘L** — блокировка; **⌘,** — настройки.
- Сверка в истории счёта создаёт фиксированную разницу с обязательной причиной. Поздние операции не переписывают эту разницу.
- Расход может войти одновременно в месячный и проектный бюджет; в общих расходах он считается один раз. «Вне бюджетов» исключает его из обоих планов.
- Исторические пересчёты используют снимки на операциях. Новые справочные курсы меняют оценку остатка. Если курса нет, итог явно помечен частичным; исходная операция сохраняется.
- Для переноса всех данных используйте «Файл → Сохранить полную копию…». CSV переносит операции, а планы/отчёты/раскладка переносятся полной копией.
- Импорт: выбрать файл → формат и колонки → сопоставления → проверить ошибки/дубли → подтвердить. До подтверждения изменения существуют только в памяти. При изменении базы предпросмотр нужно обновить.
- Восстановление: выбрать `.mubak`, ввести ключ этой копии, проверить сводку, задать новый локальный пароль, подтвердить полную замену. До замены создаётся проверенная копия текущих данных.

## Обновление приложения

Выберите **BeeSave → Проверить обновление**. Проверка доступна до разблокировки бюджета. Если есть более новая совместимая стабильная версия, нажмите **Скачать обновление**. После проверки SHA-256 выберите **Сохранить архив…**; приложение покажет файл в Finder. Распакуйте архив, завершите BeeSave, замените прежнее приложение новой копией и запустите её. База, ключи и резервные копии остаются на прежнем месте. Текущая локальная сборка устанавливается вручную и не имеет нотариализации.

Проверка не запускается в фоне. Ошибка сети, отмена или повреждённый архив не меняют установленное приложение и финансовые данные. При несовместимости показываются требования выпуска; скачивание недоступно.

Отдельная проверка реального GitHub-выпуска и его архива:

```sh
BEESAVE_UPDATE_NETWORK=1 swift test --scratch-path /private/tmp/BeeSaveTests \
  --disable-sandbox --filter AppUpdateTests.testLiveGitHubMetadataAndArchive
```

## Данные и резервные копии

Новая база: `Library/Application Support/BeeSave.noindex/vault.beesave` в sandbox-контейнере приложения. По умолчанию копии лежат рядом в `Backups.noindex`; папку можно выбрать в настройках.

При переименовании сохранены идентификатор приложения `com.mubudget.app`, сервис Keychain `com.mubudget.local.v1`, заголовок и криптографические контексты формата v1. Это постоянные технические идентификаторы: их замена нарушила бы доступ к существующим данным. Если новая база ещё не создана, BeeSave открывает прежний `MuBudget.noindex/vault.mubudget` на месте, используя прежнюю блокировку файла. Пароль, ключ восстановления, CSV v1 и полные копии `.mubak` совместимы с прежней версией; автоматического перемещения или перешифрования нет.

База и копии — AES-256-GCM контейнеры, а не открытый SQLite. Хранилище записывает согласованный снимок с проверкой ссылок и атомарной заменой файла. Промежуточный файл содержит шифротекст, имеет права 0600, удаляется после записи; журнала с открытыми данными нет. Параметры парольного Argon2id: 19 MiB, два прохода, одна полоса, случайная 128-битная соль. Случайный ключ данных и ключ восстановления — по 256 бит.

Дневная копия создаётся после первого изменения за день. Сохраняются 30 дневных и 10 служебных копий; ручные копии не удаляются ротацией. Ошибка дневной копии показывается в окне и разрешает обычный ввод; ошибка обязательной копии блокирует импорт/замену данных. Исходный CSV в базу и копии не сохраняется. Экспорт CSV — открытый текст с явным предупреждением.

## Проверки

Воспроизводимые тесты без сети:

```sh
swift test --scratch-path /private/tmp/BeeSaveTests --disable-sandbox
```

Отдельная проверка поставщиков курсов:

```sh
BEESAVE_NETWORK=1 swift test --scratch-path /private/tmp/BeeSaveTests \
  --disable-sandbox --filter NetworkTests
```

Контроль объёма 100 000 операций, 100 счетов, 500 категорий, 100 проектов и 100 отчётов:

```sh
BEESAVE_PERF=1 swift test -c release --scratch-path /private/tmp/BeeSavePerf \
  --disable-sandbox --filter PerformanceTests
```

`KeychainTests` включаются только в системном тестовом процессе с корректной подписью и разрешённой группой; неподписанный `swift test` не подтверждает работу Keychain. Для биометрии нужен настоящий Mac и участие владельца.

Изолированное окно с вымышленными данными:

```sh
xcodebuild -project BeeSave.xcodeproj -scheme BeeSave -configuration UISmoke \
  -destination 'generic/platform=macOS' -derivedDataPath /private/tmp/BeeSavePreview build
```

Откройте `/private/tmp/BeeSavePreview/Build/Products/UISmoke/BeeSavePreview.app`. Оно создаёт отдельную временную зашифрованную базу при каждом запуске, показывает предупреждение о тестовых данных и не входит в Release.

Меню **Тестовые состояния** переключает первый запуск, отсутствие счетов/операций, заполненную Главную, отсутствующий курс, архив, сохранённую раскладку и 100 000 операций. Там же доступны обе темы и размеры окна. При переключении пересоздаётся только временная тестовая база. Для воспроизводимого запуска можно передать `--ui-state=new|empty|account|filled|partial|archived|custom|volume` или переменную `BEESAVE_UI_STATE` с одним из этих значений.

## Источники и зависимости

- [Официальный Argon2 reference, tag 20190702](https://github.com/P-H-C/phc-winner-argon2/tree/20190702) включён в `Vendor/Argon2`; лицензия сохранена в исходниках и ресурсах приложения.
- CryptoKit, Security, LocalAuthentication, SwiftUI, AppKit, Charts — системные библиотеки macOS.
- Встроенный каталог обычных действующих валют и числа десятичных разрядов сверён с [SIX ISO 4217 List One](https://www.six-group.com/dam/download/financial-information/data-center/iso-currrency/lists/list-one.xml), опубликованным 17.09.2026. Металлы, тестовые и расчётные единицы фондов исключены. Каталог встроен и доступен офлайн.
- [CBR](https://www.cbr.ru/development/sxml/) и [Frankfurter](https://frankfurter.dev/) — только справочные курсы; фактические суммы перевода задаёт пользователь.

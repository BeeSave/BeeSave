# BeeSave

Локальное приложение для учёта домашнего бюджета на Mac с Apple Silicon, macOS 26.0 и новее.

BeeSave поддерживает счета в разных валютах, доходы, расходы, переводы, бюджеты, отчёты, импорт и экспорт CSV, зашифрованное хранение и полные резервные копии.

## Установка

Готовые версии доступны в [GitHub Releases](https://github.com/BeeSave/BeeSave/releases/latest). Перед заменой установленного приложения сохраните полную резервную копию бюджета и завершите BeeSave. Используйте приложенный DMG или распакуйте ZIP и перенесите BeeSave.app в папку «Программы».

## Сборка

Откройте `BeeSave.xcodeproj` в Xcode, выберите схему `BeeSave` и соберите приложение для macOS. Параметры подписи настройте для своей команды Apple Development.

Проверка ядра и представления:

```sh
swift test
```

Исходники приложения находятся в `App/`, учётного ядра — в `Sources/BudgetCore/`, представления — в `Sources/BudgetPresentation/`. Зависимости и их лицензии находятся в `Vendor/`; сведения о сторонних компонентах — в `App/Resources/ThirdPartyNotices.txt`.
